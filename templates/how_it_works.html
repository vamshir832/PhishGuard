Detection pipeline

How phishing detection works

  • 1. URL validation: The system checks whether the URL is well formed and extracts the hostname safely.
  • 2. Feature extraction: Features such as total URL length, number of dots, subdomains, IP addresses, '@' symbols, suspicious keywords, and HTTPS usage are computed.
  • 3. Model inference: A trained Random Forest or Gradient Boosting classifier evaluates the feature set and returns a prediction.
  • 4. Explanation and reporting: The result includes a human-readable explanation and a separate heuristic risk score that is distinct from the model probability.

This approach is useful for identifying structural patterns, but it cannot guarantee the intent or legitimacy of a live website in all scenarios. Users should still check the domain through trusted channels when handling credentials or financial data.
